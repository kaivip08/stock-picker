# 📈 A股短线推荐系统

每日自动筛选推荐3-5只A股短线潜力股，基于多维度技术指标综合评分。

## 功能特点

- **多策略综合评分**：放量突破、均线多头、MACD金叉、RSI反弹、价格动量
- **智能预筛选**：自动过滤ST股、停牌股、涨跌停股，聚焦活跃标的
- **风险管理**：基于ATR自动计算止损位和目标价
- **灵活配置**：通过YAML配置文件调整策略参数和权重
- **多格式输出**：支持终端展示、文本报告、CSV导出

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行

```bash
# 默认推荐5只股票
python main.py

# 推荐3只股票
python main.py -n 3

# 使用自定义配置
python main.py -c my_config.yaml

# 同时输出CSV文件
python main.py --csv
```

### Pro Scanner（中短线主板爆发力扫描器）

针对**A 股主板中短线爆发力个股**，基于"团队炒股方案"§2.1–§2.2 的三共振（题材 / 资金 / 技术）筛选体系，
输出包含大盘速览、行业 / 概念板块 Top、候选股一览表、个股深度详情（含交易计划）的完整 Markdown 报告。

```bash
# 默认输出 Top 15 候选股
python scan_pro.py

# 输出 Top 20
python scan_pro.py -n 20

# 调整深度分析的股票数量（越大越慢）
python scan_pro.py --deep-n 80

# 自定义配置
python scan_pro.py -c my_config.yaml
```

**输出说明**：
- 严格只筛选沪深主板（60xxxx / 000xxx / 001xxx / 002xxx / 003xxx），自动剔除创业板 / 科创板 / 北交所
- 综合分 = 技术(40%) + 资金(35%) + 题材(25%)
- 报告自动按方案 §4.1 个股深度分析模板生成（含交易计划 / 止损 / 风险点 Checklist）
- 候选股池给团队，**不替团队决策**

详见 `config.yaml` 中 `scanner_pro:` 区段的可调参数。

## 选股策略

| 策略 | 权重 | 说明 |
|------|------|------|
| 放量突破 | 25% | 成交量放大 + 价格突破近期高点 |
| 均线多头 | 20% | MA5 > MA10 > MA20，均线发散向上 |
| MACD金叉 | 20% | DIF上穿DEA，柱状图由负转正 |
| RSI反弹 | 15% | RSI从超卖区域反弹 |
| 价格动量 | 20% | 近期涨幅适中，趋势向上 |

## 配置说明

编辑 `config.yaml` 可自定义：

- **选股参数**：推荐数量、最小市值、排除规则
- **指标参数**：均线周期、MACD参数、RSI阈值等
- **策略权重**：调整各策略的权重比例
- **数据参数**：历史数据天数、请求间隔
- **报告设置**：输出目录、保存格式
