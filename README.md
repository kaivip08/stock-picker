# A股短线推荐系统 v2.0

每日自动筛选推荐3-5只A股短线潜力股，基于多维度综合评分：技术指标 + 资金流向 + 市场情绪 + 板块概念。

## 功能特点

- **7大策略综合评分**：放量突破、均线多头、MACD金叉、RSI/KDJ反弹、价格动量、OBV资金趋势
- **市场情绪分析**：涨停/跌停数、赚钱效应、市场情绪评分
- **资金流向追踪**：主力净流入、超大单、北向资金
- **板块热点识别**：行业板块、概念板块排行，龙头股识别
- **大盘指数监控**：上证/深证/创业板/科创50等指数行情
- **智能预筛选**：自动过滤ST股、停牌股、涨跌停股
- **风险管理**：基于ATR+SAR自动计算止损位和目标价
- **多数据源容灾**：东方财富/腾讯/新浪三源自动切换

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行

```bash
python main.py           # 默认推荐5只
python main.py -n 3      # 推荐3只
python main.py --csv     # 同时输出CSV
python main.py -c my.yaml  # 自定义配置
```

## 选股策略

| 策略 | 权重 | 说明 |
|------|------|------|
| 放量突破 | 20% | 成交量放大 + 价格突破 + OBV确认 |
| 均线多头 | 15% | MA5>MA10>MA20 + SAR趋势 + VWAP |
| MACD金叉 | 15% | DIF上穿DEA + 柱状图转正 + ROC确认 |
| RSI反弹 | 10% | RSI超卖反弹 + KDJ金叉联动 |
| 价格动量 | 15% | 涨幅适中 + 布林带位置 + 涨速加速 |
| KDJ信号 | 10% | KDJ金叉 + J值超卖反弹 |
| OBV资金 | 15% | OBV趋势 + 量价配合 |

## 技术指标覆盖

### 趋势类
MA5/10/20/60、EMA、MACD(DIF/DEA/HIST)、布林带(上/中/下轨)、SAR

### 动量类
RSI、KDJ(K/D/J)、ROC、涨速(1日/3日/5日)

### 量价类
量比、成交量均线(5日/20日)、OBV+均线、VWAP、放量突破/缩量回踩信号、成交额均值

### 资金流向
主力净流入、超大单净流入、大单净流入、小单净流出、主力净占比

### 市场情绪
上涨/下跌家数、涨停/跌停数、赚钱效应/亏钱效应、情绪评分

### 板块概念
行业板块排行、概念板块排行、板块龙头股、板块涨跌家数

### 大盘指数
上证指数、深证成指、创业板指、科创50、沪深300、中证500、中证1000

## 报告内容

运行后输出包含：

1. **市场概览** — 大盘指数涨跌、北向资金、市场情绪评分
2. **推荐汇总表** — 代码/名称/现价/涨跌幅/评分/止损位/目标价
3. **详细分析** — 每只股票的推荐理由、资金流向、止损止盈计划
4. **热门板块** — 当日涨幅前5板块及龙头
5. **风险提示**

## 配置说明

编辑 `config.yaml` 可自定义：

- **选股参数**：推荐数量、最小市值、排除规则
- **指标参数**：MA周期、MACD/RSI/KDJ参数
- **策略权重**：7个策略的权重比例
- **数据参数**：历史数据天数、请求间隔
